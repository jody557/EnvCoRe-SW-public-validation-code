# Code Availability

The public reproducibility and validation code for the corrected v3 release is available in the accompanying code package, `EnvCoRe-SW_public_code_corrected_v3_20260707`. The code uses only the Python standard library and provides scripts to validate the public release manifest and checksums, verify table counts and cross-file links, reproduce the correction-history checks, regenerate the figure source data and scan the public package for private source-path or raw-text disclosure patterns.

The private end-to-end extraction pipeline used to parse the original source reports is not redistributed because it depends on non-public source reports, private source paths, private crosswalks and private manual review context. The public code therefore supports reproducible validation and reuse of the de-identified public data release rather than redistribution of the private source corpus.
